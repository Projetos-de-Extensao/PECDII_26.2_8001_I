# Sistema de Gestão de Treinamento e Acompanhamento de Performance para a PKZ Lab

**Código da Disciplina**: IBM8936 (PECDII_26.2_8001)

## Sobre

Projeto unicamente Back-end para a empresa **PKZ Lab**, centro de treinamento de performance integrada na Barra da Tijuca. Hoje o agendamento do centro é feito só por WhatsApp, sem controle de salas, horários ou profissionais. Este projeto cadastra espaços, professores/instrutores, atividades e alunos, e aloca cada sessão a uma sala, horário e profissional sem conflito, expondo tudo por uma API.

Detalhes completos do levantamento em [docs/Iniciacao/pesquisa.md](docs/Iniciacao/pesquisa.md).

**Status**: fase de Iniciação (metodologia RUP/UP)
